Install fx-mic-mod

Back up the samples and settings on your mic (the EP-2350, sold as the Ting and as the FX Mic), swap Teenage Engineering's firmware for CircuitPython, install fx-mic-mod in one click, and get back to stock whenever you want. Each step runs in the browser while the mic is plugged in, with a drag-and-drop route if the browser won't allow it. You only do this once. After that, you change presets in the preset editor.

Drive and serial access are blocked in this view. Chrome and Edge only let a page touch USB drives and serial ports when it runs as its own tab, and this page is running inside a frame. Every step still works by drag and drop. For one-click flashing, save the standalone copy and open it in Chrome or Edge on your computer.

Before you start

  • A desktop computer with Chrome or Edge for the one-click tools. Safari and Firefox can still follow the drag-and-drop route.
  • A USB-C cable that carries data. Many charge-only cables power the mic but never show a drive.
  • A rubber band or clip. Boot mode needs the handle squeezed all the way in for the whole flash, and that's hard to do by hand.
  • Take off the lower lid to reach the USB-C port and the small reset button above it.
The mic has no charging circuit, so USB only powers it and won't charge AA batteries. On USB it stays off until you squeeze the handle all the way in.
01

Back up the mic's disk

Flashing CircuitPython erases everything on the device's own drive: your samples 1.wav to 4.wav, config.json, and any other files. Copy them off first.

  1. Plug in the mic and squeeze the handle to power it on.
  2. A drive called TING DISK appears. Some firmware versions and the official manual call it FX-MIC DISK.
  3. Pick that drive below. The page reads every file and saves them as one zip.

Doing it by hand

Open the drive in Finder or File Explorer and copy every file into a folder on your computer named something like ting-backup-2026-10-22. Include hidden files if you have edited config files with a text editor.

02

Keep a copy of the stock firmware

Teenage Engineering publishes every firmware release as a zip with a .uf2 inside. That file is your way back to the original mic, so download it now while you're thinking about it.

All versions live on the EP–2350 downloads page.

Optional: full flash dump with picotool

If you want a byte-for-byte image of the chip (firmware plus the disk), Raspberry Pi's picotool can read the RP2350's flash while the mic is in boot mode (step 03):

picotool info -a
picotool save -a ting-full-flash.bin

UnverifiedNobody has published a picotool dump of an EP-2350 yet. TE changed the boot-mode USB IDs in firmware 1.0.5, so picotool may not recognise the device, and the chip could have reads locked. The official .uf2 above is the dependable restore path.

03

Put the mic in boot mode

1 · Squeeze Hold the handle all the way in. Strap it with a rubber band.
2 · Double-click reset The small dark button just above the USB-C port. The timing is fussy, so try a few times.
3 · Look for the drive All LEDs go dark and a drive named TING BOOT (or FX MIC BOOT) appears with INDEX.HTM and INFO_UF2.TXT.
Keep the handle squeezed until the flash is finished and the device has restarted. Releasing it mid-copy cuts power to the chip.
04

Flash CircuitPython

Download the EP-2350's CircuitPython build (the same one for the Ting and the FX Mic). The board has had official builds since 10.3, so pick the stable one:

  • adafruit-circuitpython-teenage_engineering_ep2350-en_US-10.3.1.uf2 (stable, recommended)
  • Other versions and languages: circuitpython.org/board/teenage_engineering_ep2350

Doing it by hand
Drag the .uf2 file onto the boot drive (TING BOOT or FX MIC BOOT) in Finder or File Explorer, keep squeezing, and wait for CIRCUITPY to appear.

    


    
    

      
05
Install fx-mic-mod

      
This copies the fx-mic-mod files to CIRCUITPY: code.py and its modules (autotune.py, recorder.py, config_loader.py), boot.py, and a starter config.json with four presets.

      
It also needs Adafruit's driver for the mic's audio chip, adafruit_nau88l21.mpy. Download the 10.x library bundle from circuitpython.org/libraries, unzip it, and choose its lib folder below. Only the driver is copied from it. You can skip this if the driver is already on the drive.

After installing, turn the mic off and on again. From then on, a normal power-on lets the mic save recordings, and your computer sees the drive as read-only.         Hardware smoke test (code.py)
        

          
If something seems wrong, this small test checks the buttons, LEDs, handle and volume knob on their own. Squeezing the handle fills the white LEDs from the bottom, the top, middle and bottom buttons light red LEDs 1 to 3, and red LED 4 comes on past half volume. Every change prints to the serial console. Save it over code.py to run it, and reinstall fx-mic-mod afterwards.

!!
Details we couldn't verify

      
    
        
  • Drive namesAdafruit's guide says TING BOOT and TING DISK. TE's manual says FX-MIC BOOT and fx-mic disk, and their install notes accept either. TE changed the boot-mode name in 1.0.5, so expect either depending on your firmware.
    • 
        
  • Factory samplesWe don't know whether reflashing stock firmware brings back the factory sounds by itself. TE's 1.0.7 notes say factory samples are no longer loaded after sleep, which suggests they live in firmware, but keep your backup either way.
    • 
        
  • Writing the .uf2Chrome writes files through a temporary .crswap copy and then renames it. UF2 boot drives usually accept this because they read the data blocks and ignore the name, but this hasn't been tested on an EP-2350. If the device doesn't restart within a minute, drag the file instead.
    • 
        
  • Boot mode after flashingTE's double-click gesture is likely handled by the RP2350's built-in boot ROM, so it should survive the switch to CircuitPython, but we haven't confirmed it. The console's Reboot to boot mode button is the backup route, and needs the handle squeezed so the mic stays powered through the reset.
    • 
        
  • Full dumpThe picotool flash dump in step 02 is untested on this device.
    • 
        
  • Standalone fileThe saved .html copy should get drive and serial access when opened from disk in Chrome or Edge, since browsers treat local files as a secure context. If a button still reports it's blocked, serve the folder with python3 -m http.server and open http://localhost:8000.
